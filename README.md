# Kushh Kothari - Financial Analytics & Portfolio Showcase

Welcome to the GitHub repository for **Kushh Kothari's Interactive Portfolio & Executive CV Web Application**.

## 🌟 Highlights & Features

- **Interactive Showcase Mode**: Sleek dark/light theme, interactive metrics counters (**9.0/10 GPA at BSE Institute**, **300+ Startups Analyzed**, **30 Asset Classes in 10-Yr ANOVA**, **14 Extracurricular Awards**).
- **Interactive Financial Demos**:
  - **10-Year ANOVA Risk/Return Visualizer**: Built with Chart.js to display asset-class performance variance.
  - **Stock Price Forecasting Simulator**: Real-time ticker selector and time-series forecast generator.
- **Dedicated Internship Section**: Highlighting venture due diligence, market sizing (TAM/SAM/SOM), and fundraising analysis from riidl Somaiya School.
- **Live Edit Mode**: Built-in content editor with local storage persistence.
- **Executive CV Mode & 1-Click PDF Export**: Harvard / Wall Street standard single-page printable resume layout.
